# Name

The product name is **Tide and Seek**: the tidal and pilotage context the app is
built around, plus "seek" for both discovery and finding the rest of the crew.
A trademark, app-store, and domain check is still required — the pun is a
popular one, so clearing it is a gate before any public listing.

The stylised form `Tide & Seek` is fine for a logo or the website wordmark, but
every identifier, plist, manifest, and UI string uses `Tide and Seek` so nothing
has to escape an ampersand.

## Crew role naming

The back-of-fleet safety role is **Sweeper** — the flotilla and
cruising-in-company term for the boat that stays at the back and accounts for
everyone. It replaces the inherited `Tail End Charlie` (still `VoyageRole.sweeper`
and `sweeper*` in code; see [backlog.md](backlog.md)).

The role name is deliberately separate from the product name. The initial
scaffold conflated the two, producing strings such as `Be Knot Alone?`.

## Options considered

| Name | Pun / angle |
|---|---|
| Tide and Seek | Chosen. Tides, pilotage, discovery, and finding the crew |
| Backstay | Rigging that supports the mast from behind; nods to the Tail End Charlie heritage |
| Six Bells | The six-digit crew code, mapped onto ship's bells |
| Pennant | Numeral pennants are how a vessel signals digits |
| Current Affair | Tides/current plus a memorable double meaning |
| Sea You There | Crew rendezvous; cheerful and shareable |
| Charlie Noble | Real nautical term and a direct Tail End Charlie nod |
| Muster | The crew-gathering word; short and ownable |
| Knot Alone | Original working title; "knot" puns are crowded and it scans as a negation |
| Buoy Oh Buoy | Cheerful discovery-oriented option |
| Sail Mate | Straightforward crew companion; less distinctive |
| Moor or Less | Anchorages, berths, and pragmatic planning |
| Seas the Day | Optimistic and broad, though commonly used |
| Pier Pressure | Good crew joke, less suitable for a solo-first product |
