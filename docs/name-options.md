# Name Options

`Knot Alone` is the working title because it captures solo-first use and optional
crew sharing. A trademark, app-store, and domain check is still required.

Other sailing-friendly options:

| Name | Pun / angle |
|---|---|
| Knot Alone | Solo-first, but crew can share the voyage |
| Tide & Seek | Discovery, pilotage, and tidal context |
| Current Affair | Tides/current plus a memorable double meaning |
| Knot Lost | Navigation reassurance without sounding too formal |
| Buoy Oh Buoy | Cheerful discovery-oriented option |
| Sail Mate | Straightforward crew companion; less distinctive |
| Moor or Less | Anchorages, berths, and pragmatic planning |
| Seas the Day | Optimistic and broad, though commonly used |
| Nauti By Nature | Playful lifestyle brand, weaker navigation signal |
| Pier Pressure | Good crew joke, less suitable for a solo-first product |

Suggested shortlist: **Knot Alone**, **Tide & Seek**, and **Current Affair**.
