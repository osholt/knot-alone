# Tester release notes

## 1.1.0 — next closed-test build

- Flat, wider and manually controllable chart camera.
- Bundled offline astronomical tide heights for three Solent stations.
- Time-selectable area wind forecast.
- Manual MOB marker and recovery view.
- Local NMEA TCP received-AIS layer and a clearly labelled synthetic replay.
- Final inherited road-routing, roundabout and lane-guidance code removed.
- Verified website links can now open a shared passage or private voyage
  invitation directly in the installed app, with a safe web fallback.
- Public privacy, terms, tester-install and support pages now match the mobile
  release surfaces.
- iOS accepts GPX files which arrive with a generic file type more reliably.

See [`RELEASE_NOTES.md`](../RELEASE_NOTES.md) for the test checklist and safety
limitations.
